## 四、技术/协作决策

- **决策1（技术栈方向）**：选型 React + TypeScript + Vite + TailwindCSS + shadcn/ui 作为前端技术栈，统一使用函数式组件 + Hooks，禁止 Class 组件。
- **决策2（Mock机制）**：前期不等待后端就绪，前端使用 Mock 数据独立开发。Mock 数据需贴近真实文物信息。
- **决策3（代码协作方式）**：采用 GitHub Flow 分支策略，各成员在 feature 分支开发，完成后提 PR 合并到 develop 分支。

## 六、其他讨论内容

1. **关于 UI 风格参考**：全体一致同意参考大英博物馆官网（https://www.britishmuseum.org/）的视觉风格——深色主色调 + 金色点缀，营造博物馆级、学术感的用户体验。
2. **关于子系统间协作**：本子系统（子系统2）需依赖知识图谱构建子系统（子系统1）提供的文物数据接口，以及后台管理子系统（子系统5）提供的用户数据接口。初期以 Mock 数据独立开发，后续对接。
3. **关于课程设计时间规划**：预计开发周期为 4-5 周，需在课程结束前完成全部功能开发与文档撰写。

## 一、系统概述

海外文物知识服务系统（Overseas Artifacts Knowledge Service System）是一个面向海外藏中国文物的知识管理与服务平台。系统汇集了全球 6 家博物馆、5400+ 件中国文物的详细资料，提供文物浏览、多维筛选、全文搜索、对比分析、知识图谱、时间轴、地理分布、统计分析等功能，帮助用户全面了解和探索海外流散的中国文物。

## 二、快速入门

### 2.1 访问系统

在浏览器中打开系统网址，进入首页。

### 2.2 系统环境要求

| 环境 | 最低要求 |
| :--- | :--- |
| 浏览器 | Chrome 90+ / Edge 90+ / Firefox 88+ |
| 网络 | 需连接互联网（访问后端 API 和地图服务） |
| 屏幕分辨率 | 推荐 1280×720 及以上 |

### 2.3 注册与登录

| 操作 | 步骤 |
| :--- | :--- |
| **注册账号** | ① 点击页面右上角"登录"按钮 → ② 点击"还没有账号？立即注册" → ③ 填写用户名（3-20字符）、昵称、邮箱、密码（6位以上） → ④ 点击"注册"按钮 |
| **登录系统** | ① 点击页面右上角"登录"按钮 → ② 输入用户名/邮箱和密码 → ③ 点击"登录"按钮 |
| **退出登录** | ① 点击页面右上角用户头像 → ② 在下拉菜单中点击"退出登录" |

> **提示**：系统提供测试账号（用户名：`admin`，密码：`123456`），可用于快速体验系统功能。部分功能（收藏、评论、浏览记录）需要登录后使用。

## 四、功能详细说明

### 4.2 文物浏览

文物浏览是系统的核心功能页面，支持全维度文物检索。

#### 4.2.1 筛选功能

左侧筛选面板提供三维度过滤：

| 筛选项 | 说明 |
| :--- | :--- |
| **文物类型** | 按品类筛选（如陶瓷、绘画、雕塑、青铜器等），括号内显示各品类文物数量 |
| **年代/朝代** | 按历史朝代筛选（如唐代、宋代、明代等） |
| **博物馆** | 按收藏机构筛选（如大英博物馆、普林斯顿大学艺术博物馆等） |

> **操作提示**：
> - 点击筛选项即可应用筛选，已选中的筛选项高亮显示。
> - 所有筛选条件可叠加使用（同时按类型+朝代+博物馆筛选）。
> - 点击已选标签中的 ✕ 可取消该筛选条件。
> - 点击"重置"按钮可清除所有筛选条件。
> - 移动端用户需点击顶部"筛选"按钮打开筛选面板。

#### 4.2.2 搜索与排序

| 功能 | 说明 |
| :--- | :--- |
| **名称搜索** | 顶部搜索框输入文物名称关键词，实时搜索 |
| **排序方式** | 下拉菜单选择排序字段：名称 / 年代 / 更新时间 |
| **升降序** | 点击排序字段旁的箭头按钮切换升序 ↑ / 降序 ↓ |

#### 4.2.3 视图切换

| 视图模式 | 适用场景 |
| :--- | :--- |
| **卡片视图** | 图文并茂，适合浏览和欣赏（默认 4 列网格，自适应屏幕宽度） |
| **列表视图** | 信息密集，适合快速查找和对比筛选 |

点击顶部工具栏的卡片/列表图标切换。

#### 4.2.4 文物对比

| 操作 | 说明 |
| :--- | :--- |
| **添加对比** | 卡片视图中悬停文物卡片，点击出现的"对比"按钮；列表视图中直接点击"加入对比" |
| **数量限制** | 最多同时对比 3 件文物 |
| **查看对比** | 点击顶部工具栏"对比 (N)"按钮跳转到对比页面 |

#### 4.2.5 分页浏览

底部页码控件支持上一页/下一页和直接跳转指定页，每页展示 12 件文物。

### 4.3 文物详情

点击任意文物卡片进入详情页，查看文物的完整信息。

#### 4.3.1 图片浏览

| 功能 | 说明 |
| :--- | :--- |
| **主图查看** | 左侧展示文物主图，点击可进入全屏缩放模式 |
| **缩略图切换** | 多张图片时，点击下方缩略图切换主图 |
| **全屏模式** | 点击主图进入，背景变暗图片居中，按 Esc 或点击 ✕ 关闭 |

#### 4.3.2 文物信息

右侧信息区域包含：

| 信息项 | 说明 |
| :--- | :--- |
| **品类徽章** | 彩色徽章标注文物类型 |
| **中英文名称** | 中文名 + 英文名（斜体） |
| **关键信息** | 4格卡片展示：年代、地区/文明、材质、尺寸（高×宽×深 cm） |
| **博物馆信息** | 金色边框高亮卡片，显示收藏博物馆和所在地 |
| **文物描述** | 完整的中文描述文本 |
| **历史背景** | 文物相关的历史背景介绍 |

#### 4.3.3 知识图谱三元组

以结构化格式展示文物与相关实体的关系：

> **[文物名称]** —*属于*→ **[文物类型]**
> **[文物名称]** —*材质*→ **[材质名称]**
> **[文物名称]** —*年代*→ **[朝代名称]**
> **[文物名称]** —*收藏于*→ **[博物馆名称]**

蓝色 = 主语，金色箭头 = 谓语，绿色 = 宾语。

#### 4.3.4 标签

文物标签以可点击徽章形式展示，点击标签跳转到浏览页面并自动搜索该标签关键词。

#### 4.3.5 评论区

| 功能 | 操作说明 |
| :--- | :--- |
| **发表评论** | 需要登录。在文本框中输入内容，按回车或点击发送按钮 |
| **点赞评论** | 点击评论旁的心形图标点赞/取消点赞（已点赞显示为金色 ❤） |
| **回复评论** | 点击评论下的"回复"展开回复区域，输入内容后发送 |
| **查看回复** | 点击"展开回复"查看所有回复内容 |

#### 4.3.6 操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| **❤ 收藏** | 收藏/取消收藏该文物（需登录） |
| **📋 分享** | 复制当前文物链接到剪贴板 |
| **🔗 访问博物馆官网** | 在新标签页打开博物馆官方页面（仅部分文物有此按钮） |
| **📊 加入对比** | 添加到文物对比列表 |

#### 4.3.7 相关推荐

页面底部展示 4 件相关文物推荐，基于同朝代、同材质、同类型、同博物馆等维度自动计算。

### 4.4 搜索

#### 4.4.1 普通搜索（/search）

| 功能 | 说明 |
| :--- | :--- |
| **关键词搜索** | 在搜索框中输入文物名称、博物馆名、朝代等关键词，点击搜索按钮 |
| **搜索历史** | 自动保存最近 8 条搜索记录（存储在浏览器本地），点击可快速复用 |
| **清除历史** | 点击搜索历史标签上的 ✕ 删除单条记录 |
| **导出结果** | 支持导出为 CSV 格式（表格数据）和 JSON 格式（结构化数据） |

#### 4.4.2 高级搜索（/advanced-search）

提供多条件组合精确查询：

| 搜索条件 | 输入方式 |
| :--- | :--- |
| **关键词** | 文本输入（文物名称） |
| **文物类型** | 下拉选择（选项从实际数据中动态加载） |
| **收藏博物馆** | 下拉选择（选项从实际数据中动态加载） |
| **年代范围** | 起始年份 + 结束年份（支持负数表示公元前年份，如 -221 表示公元前221年） |

点击"搜索"按钮执行查询，点击"重置"清空所有条件。结果同样支持 CSV/JSON 导出。

### 4.7 知识图谱查询

#### 4.7.1 图谱浏览

| 操作 | 说明 |
| :--- | :--- |
| **搜索文物** | 在搜索框中输入文物名称，下拉列表显示匹配结果（含缩略图、名称、年代、博物馆） |

| **图谱交互** | 鼠标拖动平移、滚轮缩放节点和关系 |
| **节点说明** | 不同颜色代表不同实体类型（文物=蓝色、博物馆=红色、朝代=绿色、艺术家=紫色、地点=橙色、材质=青色） |
| **查看详情** | 点击节点在右侧面板显示该实体的详细信息 |
| **图例** | 右下角图例说明各颜色对应的实体类型及数量 |
| **导出** | 支持 CSV 和 JSON 格式导出图谱数据 |

#### 4.7.2 自然语言查询

| 功能 | 说明 |
| :--- | :--- |
| **输入查询** | 用自然语言描述查询需求，如"唐代的所有瓷器"、"大英博物馆的绘画" |

## 五、常见问题（FAQ）

| 问题 | 解答 |
| :--- | :--- |
| **Q: 为什么无法收藏文物？** | A: 收藏功能需要登录。请先注册账号或使用测试账号（admin/123456）登录。 |
| **Q: 搜索不到想要的文物怎么办？** | A: 尝试使用高级搜索，通过年代范围、文物类型、博物馆等多条件组合进行精确查询。也可以使用知识图谱的自然语言查询功能。 |
| **Q: 对比最多可以加几件文物？** | A: 系统支持同时对比 2-3 件文物。超过上限需要先移除已有对比项。 |
| **Q: 文物图片加载不出来？** | A: 请检查网络连接。如果图片持续加载失败，可能是后端服务暂时不可用，请稍后重试。 |
| **Q: 如何导出数据？** | A: 在搜索、高级搜索和知识图谱页面均提供 CSV / JSON 导出按钮，点击即可下载。 |
| **Q: 浏览记录能保存多少条？** | A: 系统最多保存最近 50 条浏览记录，超出后自动覆盖最早的记录。 |

## 七、附录

### 7.1 快捷操作速查

| 操作 | 快捷方式 |
| :--- | :--- |
| 返回首页 | 点击导航栏 Logo 或"首页"链接 |
| 开始浏览文物 | 首页 → 点击"开始探索" |
| 对比文物 | 浏览页 → 悬停文物卡片 → 点击"对比"按钮 |
| 查看全屏图片 | 文物详情页 → 点击主图 |
| 搜索文物 | 任意页面 → 顶部搜索图标 或 Ctrl+K |
| 导出数据 | 搜索/高级搜索/知识图谱页 → 点击导出按钮 |

### 7.2 技术栈说明

| 层级 | 技术 |
| :--- | :--- |
| 前端框架 | React 18 + TypeScript (strict) |
| 构建工具 | Vite 5 |
| 样式方案 | TailwindCSS 3 + shadcn/ui 组件库 |
| 状态管理 | Zustand |
| 路由管理 | React Router v6 |
| 图表可视化 | ECharts 5 |
| 地图服务 | Leaflet + OpenStreetMap |
| 图标库 | Lucide React |

### 7.3 数据来源

系统数据来源于全球 6 家知名博物馆馆藏的中国文物：

1. 大英博物馆 (British Museum)
2. 普林斯顿大学艺术博物馆 (Princeton University Art Museum)
3. 大都会艺术博物馆 (The Metropolitan Museum of Art)
4. 维多利亚与阿尔伯特博物馆 (Victoria and Albert Museum)
5. 皇家安大略博物馆 (Royal Ontario Museum)
6. 克利夫兰艺术博物馆 (Cleveland Museum of Art)

共计 5400+ 件文物，涵盖陶瓷、绘画、雕塑、青铜器、玉器、漆器、纺织品等多种类型，时间跨度从商周至明清。

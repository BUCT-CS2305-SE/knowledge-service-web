## 四、技术/协作决策

- **决策1（Mock机制确认）**：在第8周决策基础上进一步细化——前端开发初期使用 Mock 数据独立开发，Mock 数据需严格遵循接口文档格式。Mock 数据生成由赵子皓统一编写脚本，确保数据格式一致性。

- **决策2（UI风格锁定）**：全体一致确认参考大英博物馆官网（https://www.britishmuseum.org/）的视觉风格——深色主色调 + 金色点缀，营造博物馆级学术感体验。由刘思益在TailwindCSS配置中定义专用设计令牌（design tokens）。

- **决策3（接口文档先行）**：在正式编码前，由郭展宏先完成《API接口需求初稿》并向全团（含知识图谱组、后台组）发出，确保各子系统对数据格式达成一致后再大规模开发。

- **决策4（分支策略细化）**：采用 GitHub Flow，各成员在 `feature/<模块名>` 分支开发，完成后提 PR 合并到 `develop` 分支。郭展宏负责代码审核与合并。禁止直接在 `main`/`develop` 分支推送。
